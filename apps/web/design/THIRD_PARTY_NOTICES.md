- Fluid Functionalism: sidebar registry source and preset sa1FQfCxG4 were inspected and adapted, then visually aligned to the owner's current saBErysbKa pill/inset reference in its live browser playground. MIT ©2026 Micka Touillaud; see FLUID-LICENSE.txt. Reference: https://www.fluidfunctionalism.com/docs/sidebar?preset=saBErysbKa . - Recharts 3.10.1: MIT, React 19 peer compatibility verified from npm metadata, installed with lifecycle scripts disabled. Official BarChart API inspected. Used for the real-history activity plot; accessible data table included. Chart chunk is lazy loaded (~106KB gzip).
- Motion 14.6.0 and Lucide React 1.61.0: existing pinned project libraries, used for transitions, selection and iconography.
- Magic UI: dock source at commit efe76fc5755eca1142dd4f74c1d6f0ace2887e3c and MIT license inspected; source/license retained for reference. Magnifying desktop behavior was rejected in favor of the owner's mobile-only labeled glass navigation. Do not claim this source is installed unchanged.
- React Bits: prior Dither source/license retained under src/components/effects/vendor (MIT + Commons Clause). Current landing uses the project's ASCII veil; the retained Dither component is not a claim of a running live 3D scene.

Malan source was inspected read-only for a reusable dock. No suitable dock was reused and no files in Malan were changed.
