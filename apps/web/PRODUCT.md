# Product authority

Hardcase is one React/TypeScript + Node local testing application under the canonical repository, with `apps/web` as its UI workspace. The main backend agent owns testing/security logic and native packaging. The frontend owns UI, typed adapter and the unified web launcher. The previous sibling checkout is preserved, not used for release.

Users prepare authorized tests, observe real execution, investigate evidence and export reproducible records. No sign-in is mandatory locally. Levels 1–5 work on disposable fixtures; explicit owned loopback scenarios support levels 1–2. Targets in the All projects view are derived from actual engine history, grouped by origin/fixture variant; they are not independent cloud project objects. Charts state their loaded-history scope. Fixtures and suspected findings are labeled.
